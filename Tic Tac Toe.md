# Tic Tac Toe Game

## Description
A simple Tic Tac Toe game developed using C language. Two players can play the game by taking turns.

## Features
- Two-player gameplay
- Display game board
- Check winning condition
- Identify draw condition

## Concepts Used
- 2D Arrays
- Loops
- Conditional Statements
- Functions

## Language
C Programming
