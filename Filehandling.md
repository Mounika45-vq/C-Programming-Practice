# File Handling Program

## Description
A C program that demonstrates how to create, read, write, and manage files.

## Features
- Create a file
- Write data into a file
- Read data from a file
- Close the file

## Concepts Used
- File Pointers
- fopen()
- fprintf()
- fscanf()
- fclose()

## Language
C Programming
